# Nested Meta EP6 local-partial reduction

**Status:** fixture-only proposal. The shared source tree was not modified. No engine build, model load, or GPU call was made in this lane.

## Failure addressed

V54's generic outer Meta2 fallback copies an inner Meta3 output with local partial split state. That reaches `ggml_backend_tensor_copy_async()` at `ggml-backend.cpp:529-548`; its synchronized fallback calls `ggml_backend_tensor_get()`, which dispatches to `ggml_backend_meta_buffer_get_tensor()`. The latter supports real split axes and MIRRORED, but intentionally has no read case for private `local_partial_axis=12`; it aborts at `ggml-backend-meta.cpp:3036`.

The private candidate handles this only at the explicit nested Meta2×3 allreduce boundary. It directly reads all six physical leaf tensors, synchronizing each producer backend first; sums the three rank contributions within each island, then adds the two island totals; and writes the completed sum back to every physical leaf before synchronizing them. It does not call the unsupported generic Meta `buffer_get_tensor()` for local partials, and never treats rank 0 as MIRRORED. Direct local-partial reads outside a recognized collective remain fatal by design.

The relevant V54 source points are `ggml-ep-private.h:12` (local-partial axis), `ggml-backend-meta.cpp:2939-3038` (buffer get lacks a local-partial case), `:4834-4947` (generic allreduce fallback), and `ggml-backend.cpp:529-548` (async-copy fallback can call the Meta buffer getter). The captured baseline file SHA-256 is `cea773c4632c54bfc00cee63a1fe02cdc46d2fabc7d5437189489bed185a7131`.

The candidate is deliberately limited to two outer Meta children, three physical children per island, and same-shape contiguous F32 tensors. It fails closed on asymmetric partial state, unexpected topology, or unsupported dtype/layout. A disabled leaf contributes zero, matching the existing fallback's empty-slice handling.

This host-staged path is a correctness fallback, not a performance proposal. It transfers each partial to host, computes the two-level sum, writes the result to all six GPUs, and synchronizes before consumers run. A production replacement should use an explicit inner three-rank island reduction followed by inter-island reduction, with an explicit completion edge before the outer transfer. This fixture makes no throughput, DPA, or model-parity claim.

## Ownership and stream order

- The graph output tensors, leaf descriptors, and backend pointers are borrowed from the active Meta graph for the duration of `allreduce_fallback`; the candidate stores no pointers after returning.
- The candidate synchronizes all six leaf backends before reading. This orders local partial writes before the host reads them.
- Host scratch is bounded to six 4,096-float rank chunks plus one result chunk. It is owned by the fallback invocation.
- Each result chunk is written to all six leaf tensors. The candidate synchronizes all six backends before reusing host scratch or returning to the parent scheduler.
- The output buffer metadata remains a partial descriptor, but the collective boundary has physically written the same global sum to all six leaves. The downstream output-partial convention may therefore treat that tensor as synchronized. No unverified metadata alias is introduced.
